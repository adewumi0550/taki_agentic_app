# QR codes — DevFest Owerri 2026

Generated with segno at version 6, error correction **H** (the highest),
so they still scan from the back of the room or off a projector. Black is
DevFest Black 02 `#1E1E1E` on Off White `#F0F0F0`. PNG for slides, SVG
for print — the SVG scales to any size without going fuzzy.

| file | points at | public? |
|---|---|---|
| `deck.*` | the talk deck artifact | **No — private until shared** |
| `quiz.*` | the DevFest Owerri quiz | Yes |
| `money.*` | The Money Desk demo | Yes |
| `repo.*` | github.com/adewumi0550/taki_agentic_app | Yes |

**Before putting `deck` on a slide:** the artifact is private, so a scan
gets an access screen for everyone but the owner. Open the artifact, use
Share, then test the QR with a phone that is not signed in as you.

The two Cloud Run codes stop working when those services are deleted.
